Bloom SPV helper — stub filter tag.

## Features

- BTC path m/84'/0'/0'
- Local derive + address codec
- C++20, CMake, no third-party fetch

## Prerequisites

- CMake 3.20+
- A C++20 compiler
- Git

## Getting Started

```bash
git clone <repo-url>
cd bloom-spv
cmake -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## Project Structure

```
include/bloom-spv/wallet.h
src/wallet.cpp
src/main.cpp
tests/test_core.cpp
```
